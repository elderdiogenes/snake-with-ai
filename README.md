# Snake Game AI

Snake game developed in Python, featuring an AI implementation to explore decision-making and movement algorithms. Developed for educational purposes.

# About the project

A Snake game developed in Python using the Pygame library.

The initial goal was to learn programming from scratch. After completing the game, I decided to explore different types of Artificial Intelligence and experiment with implementing them. So far, the project features one AI that is still under development.

This project is being developed for educational purposes as part of my learning journey in Computer Science.

# Features

Snake movement
Apple generation
Tile-based game board
Collision detection
Experimental AI implementation (under development)

# How to Run

1. Clone the repository

```bash
git clone https://github.com/elderediogenes/snake-with-ai.git
```

2. Navigate to the project folder

```bash
cd snake-with-ai
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the game

```bash
python main.py
```

# Project Status

The game is currently functional, featuring manual and AI-controlled gameplay.

Player can control the snake manually using the keyboard, but the AI is currently the primary control system and handles movement automatically.

AI implementation is still under development and does not always make the correct movement decisions.

This project is a work in progress, and improvements to the AI are planned.
